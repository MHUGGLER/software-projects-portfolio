# Task Organizer (Java Console Application)

## 📌 Project Overview
This project is a **console-based task organizer** developed in **Java**, designed to demonstrate **object-oriented programming (OOP)** principles, **layered architecture**, and **clean code practices**.

The project was created as part of my software portfolio to showcase my understanding of Java fundamentals, problem-solving skills, and software organization.

---

## 🚀 Features
- Add new tasks with priority
- List all tasks
- Mark tasks as completed
- Remove tasks by ID
- Simple and intuitive console menu

---

## 🛠 Technologies & Concepts
- Java
- Object-Oriented Programming (OOP)
- Layered Architecture (Model, Service, UI)
- Console Input/Output
